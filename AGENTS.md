# gitchess

gitchess is a learning project exploring the idea of “FUSE for Git” through a Git-backed chess game.

## Collaboration

- Work collaboratively in small, understandable steps.
- Explain the proposed change and wait for agreement before implementing it. Once a step is agreed, carry it out without repeatedly asking for permission.
- Freely inspect files, research documentation, and run non-mutating checks to inform proposals.
- Explain meaningful design decisions and unfamiliar Git concepts. Avoid line-by-line walkthroughs unless requested.
- Keep changes focused on the agreed step and pause for review before moving on.
- Do not start or run the SSH server from within Codex. The user manages the server in their own terminal; provide commands when needed.
